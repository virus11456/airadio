# 心情規則

> 環境訊號 → 對應情緒 → 影響選歌。

## 天氣

- 晴 → 維持時段預設
- 多雲 → 慢一點點
- 雨 → 多放 jazz / bossa nova / 中文慢歌 / city pop slow
- 雷雨 → 避開激昂歌曲，鋼琴或 ambient
- 颱風 → 放老歌、暖一點

## 星期

- 週一早 → 輕快不沉重，BPM 100+
- 週三 → 平穩，工作向
- 週五晚 → funk / disco / 釋放
- 週六全天 → 放鬆基調，可以多放慢歌
- 週日傍晚 → 偏溫暖、避免太嗨（怕影響週一情緒）

## 時段轉場

- 從工作切到下班（18:00）→ 至少一首人聲過渡
- 從晚間切到睡前（23:00）→ BPM 漸降，最後 30 分純樂器
